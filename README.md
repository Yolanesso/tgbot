# Telegram Бот для Задач и Напоминаний

Бот для управления задачами и напоминаниями с удобным интерфейсом и поддержкой часовых поясов.

## Возможности

- ⏰ **Установка часового пояса** - настройка вашего часового пояса для корректной работы напоминаний
- 🔔 **Напоминания** - создание напоминаний с выбором даты и времени, управление (изменение времени, удаление)
- 📝 **Задачи** - создание списка задач с возможностью редактирования и удаления
- 💝 **Поддержка автора** - информация о том, как поддержать проект
- 📊 **Аналитика** - команда `/stats` для владельца бота с подробной статистикой пользователей, задач и напоминаний

## Установка

1. Клонируйте репозиторий или скачайте файлы
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
## Запуск

```bash
python bot.py
```

## Использование

1. Запустите бота командой `/start`
2. Выберите нужную функцию из главного меню:
   - **Установить часовой пояс** - выберите ваш часовой пояс из списка
   - **Напоминания** - создайте напоминание или управляйте существующими
   - **Задачи** - создайте задачу или управляйте списком задач
   - **Поддержать автора** - информация о поддержке проекта

### Создание напоминания

1. Выберите "🔔 Напоминания" → "➕ Создать напоминание"
2. Введите текст напоминания
3. Введите дату в формате ДД.ММ.ГГГГ (например, 25.12.2024)
4. Введите время в формате ЧЧ:ММ (например, 14:30)

### Управление напоминаниями

- Изменить время напоминания
- Удалить напоминание

### Управление задачами

- Создать новую задачу
- Редактировать существующую задачу
- Удалить задачу
- Отметить задачу как выполненную/не выполненную

### Аналитика (только для владельца)

Команда `/stats` позволяет владельцу бота просматривать подробную статистику:

- Общее количество пользователей
- Активные пользователи (сегодня, за неделю, за месяц)
- Статистика по задачам (всего, выполнено, активных, процент выполнения)
- Статистика по напоминаниям (всего, будущих, прошедших)
- Топ-5 активных пользователей
- Ежедневная активность за последние 7 дней

Для использования аналитики необходимо указать `OWNER_ID` в файле `.env`.

## Технологии

- `python-telegram-bot` - библиотека для работы с Telegram Bot API
- `aiosqlite` - асинхронная работа с SQLite
- `pytz` - работа с часовыми поясами
- `python-dotenv` - безопасное хранение секретных данных в .env файле

## База данных

Бот использует SQLite базу данных (`bot_database.db`) для хранения:
- Настроек пользователей (часовой пояс)
- Напоминаний
- Задач

База данных создаётся автоматически при первом запуске.

## Примечания

- Напоминания проверяются каждую минуту
- Все времена сохраняются в UTC и конвертируются в часовой пояс пользователя
- Бот работает 24/7 при условии, что скрипт запущен
